## 2026-11-15 — первая версия: создание сделок amoCRM из xlsx через браузер

**Сделано**
- `excel_reader.py` — разбор отчёта: школа из «Школа: …», колонки ищутся по заголовкам (Класс, ФИО/Телефон КР/РК), телефон → `+7…`, лишний текст из ячеек → примечание.
- `amo_bot.py` — Playwright (постоянный профиль `browser-profile/`, вход вручную один раз): Сделки → Новая сделка → название `<класс> <школа>` → КР → Сохранить → РК → Сохранить. Селекторы в `SEL`, поля ищутся по видимым подписям («Сделка #», «Добавить контакт», «Раб. тел.», «Должность»).
- `main.py` — CLI: `--preview`, `--limit`, `--step`, `--sheet`, `--probe`; `progress.json` защищает от дублей; при ошибке — стоп + скриншот в `logs/`.
- `run.bat`, `config.json` (нужно вписать `amo_url`), `README.md`.

**Состояние**
- Не git-репозиторий, ничего не закоммичено. `.venv` создан, Chromium для Playwright скачан (Chrome в системе не найден).
