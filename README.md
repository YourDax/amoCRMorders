# Сделки в amoCRM из отчёта

Программа для Windows: загружаете xlsx-отчёт по мероприятию, нажимаете «Создать сделки», и она сама
заводит сделки в amoCRM (https://fmaniaamo.amocrm.ru) так, как это делал бы человек.

## Установка

1. Откройте [Releases](https://github.com/YourDax/amoCRMorders/releases/latest) и скачайте **SdelkiAmoCRM-Setup.exe**.
2. Запустите установщик и нажмите «Установить». Права администратора не нужны: программа ставится
   в ваш профиль (`%LOCALAPPDATA%\Programs\SdelkiAmoCRM`), ярлыки появятся на рабочем столе и в «Пуске».
   - Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**
     (установщик не подписан платным сертификатом).

Нужен Windows 10 или 11 с браузером Microsoft Edge (он есть в Windows по умолчанию).

**Обновление:** скачайте новый установщик из Releases и запустите — он обновит программу поверх старой.
Вход в amoCRM и список созданных сделок сохранятся (они хранятся отдельно, в `%LOCALAPPDATA%\amoCRMorders`).

**Удаление:** «Параметры → Приложения → Сделки amoCRM → Удалить».

> Почему установщик, а не один exe: однофайловый exe при запуске распаковывает себя во временную папку,
> и Защитник Windows принимал его за вирус (`Wacatac.B!ml`, ложное срабатывание). Установленная программа
> так не делает, и Защитник её не трогает.

## Как пользоваться — 3 шага

1. Запустите ярлык «Сделки amoCRM». Откроется окно программы.
2. Перетащите в окно файл отчёта `.xlsx`.
3. Проверьте воронку и нажмите **«Создать N сделок»**.

В первый раз откроется отдельное окно amoCRM — войдите в аккаунт, вход запомнится.
Пока идёт работа, окно amoCRM лучше не трогать. Ход работы виден на полоске прогресса.
Закрыли окно программы — через пару минут она завершится сама (если не идёт создание сделок).

## Что делает программа с каждой сделкой

1. Открывает выбранную воронку → «Новая сделка».
2. Название: `<класс> <школа>`, например `4в Под_18-сп2`; для детского сада — `гр.<группа> <сад>`, например `гр.11 1368-до4`.
3. Контакт **КР** (в детском саду — **ВС**, воспитатель; всегда первым): ФИО, «Раб. тел.» (с примечанием в скобках),
   «Должность» = `КР` / `ВС`, «Название компании» = название сделки → «Сохранить».
4. Контакт **РК** так же, «Должность» = `РК` → «Сохранить».

## Удобства

- **Красные строки.** Если класс в отчёте помечен красным (заливка или текст ячейки класса, ФИО, телефона, доп. информации) —
  строка приходит без галочки с меткой «красная в файле». Учитываются и бледно-красная заливка, и красный из темы; оранжевый — нет.
- **Отказы.** Классы, у которых в «Доп.Информации» написано про отказ или другого фотографа, приходят без галочки (метка «отказ?»).
- **Проверка данных.** Неправильный или пустой телефон, нет ФИО и т. п. подсвечиваются жёлтым; подсказка — при наведении.
- **Школа или детский сад.** Определяется по файлу: «Школа:» / «Класс» / «ФИО КР» — школа; «ДС:» / «Группа» /
  «ФИО Воспитателя» — детский сад. Переключатель «Школа | Детский сад» сверху меняет вручную: названия сделок и КР/ВС
  перестраиваются сами. Лист без единого контакта (например «Досъем») пропускается.
- **ФИО с заглавных букв.** «диля халимовна» → «Диля Халимовна», и в файле, и при правке в таблице.
- **Правка.** Любую ячейку можно исправить. Поле «Школа» («Детский сад») сверху меняет название во всех сделках сразу.
  «×» у телефона убирает контакт, 🗑 убирает строку, «Вернуть как в файле» отменяет все правки.
- **Без дублей.** Созданные сделки запоминаются: при повторной загрузке файла они помечены «уже создана».
- **Ошибки.** Программа повторяет попытку; если сделка уже сохранилась с КР — дозаполняет её, а не создаёт новую.
  Не получилось — сделка помечается, программа идёт дальше. «Повторить ошибочные» запускает только их.
- **Проверять перед сохранением.** С этой галочкой программа останавливается перед каждым «Сохранить».

## Если что-то пошло не так

Журнал и скриншоты ошибок лежат в `%LOCALAPPDATA%\amoCRMorders\logs` (вставьте этот путь в адресную строку Проводника).
Их можно отправить разработчику.

## Для разработчика

Запуск из исходников (нужен Python 3.12):

```bash
run.bat
```

Сборка локально (результат — папка `dist\SdelkiAmoCRM` и, если установлен Inno Setup 6, `dist\SdelkiAmoCRM-Setup.exe`):

```bash
build.bat
```

Новый релиз: поднять `VERSION` в `paths.py`, закоммитить и отправить тег — GitHub Actions соберёт установщик и опубликует релиз.

```bash
git tag v1.0.9
```

```bash
git push origin v1.0.9
```

Файлы:

- `app.py` — сервер приложения (Flask) и фоновый поток с браузером; `static/index.html` — интерфейс.
- `amo_bot.py` — действия в amoCRM (Playwright; браузер Edge → Chrome → Chromium). Селекторы — в `SEL`.
- `excel_reader.py` — разбор отчёта. `paths.py` — пути к ресурсам и данным, версия.
- `config.json` — адрес amoCRM, порт, скорость кликов, запасной список воронок.
  Личные настройки поверх — `%LOCALAPPDATA%\amoCRMorders\config.json`.
- `SdelkiAmoCRM.spec` (программа папкой), `installer.iss` (установщик Inno Setup), `build.bat`,
  `.github/workflows/release.yml` — сборка и релизы.
- `main.py` — консольный вариант (`python main.py отчет.xlsx --preview`, `--probe`).
- Для автопроверок: `AMO_HEADLESS=1` запускает браузер без окна.
